# 냥코비 캐릭터 이미지

이 폴더에 아래 이름 그대로 PNG를 넣으면 게임이 자동으로 사용합니다.
파일이 없는 단계는 기존 도형으로 대신 그려지고, 게임은 멈추지 않습니다.

| 단계 | 기본 표정 (필수) | 시무룩 표정 (선택) | 화면에 맞춰지는 최대 크기 (게임 좌표) |
|---|---|---|---|
| 알 | `egg.png` | `egg_sad.png` | 가로 220 × 세로 280 |
| 아기 | `baby.png` | `baby_sad.png` | 가로 260 × 세로 260 |
| 어른 | `adult.png` | `adult_sad.png` | 가로 380 × 세로 380 |

## 규격
- 형식: PNG, **배경 투명**
- **캐릭터 발끝이 이미지 맨 아래 가장자리에 닿게** 여백 없이 자르기 (발 위치 정렬 기준)
- 좌우 여백은 같게 (캐릭터가 가운데 서도록)
- 비율은 자유. 위 "최대 크기" 상자 안에 비율을 유지한 채 맞춰진다
- 권장 해상도: 표시 크기의 약 2배 (예: 어른 760 × 760 이하, 아기 520 × 520 이하) — 휴대폰에서 선명하게
- 시무룩 이미지가 없으면 기본 이미지를 회색빛으로 어둡게 해서 보여준다

크기·발 위치 기준값은 `src/art/placeholders.ts`의 `CHARACTER_ART`, `CHARACTER_FEET_Y`에서 바꾼다.
